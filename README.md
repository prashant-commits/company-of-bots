# Company of Bots

An open-source job-seeker app where bots find roles and prepare applications from what you tell them.
Status: pre-alpha, expect breaking changes.
v1 is for technical users who can clone a repo and run Node 24.
It needs git 2.31 or newer: setting up, cloning and syncing the data repo refuse an older git before they change anything.
Product requirements: [docs/prd/company-of-bots.md](docs/prd/company-of-bots.md)
